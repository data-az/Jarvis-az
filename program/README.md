# JARVIS AZ v2.4.9

Голосовой ассистент с красивой визуализацией. Сам себе сделал, делюсь.

# Что это вообще?

Это голосовой помощник для Windows. Говоришь ему команды, он делает. Визуализация красивая, с 3D кольцами и частицами. Всё работает через микрофон, реагирует на голос.

# Что умеет?

- Слушает голос через микрофон
- Управляет громкостью (скажи "звук плюс 10" или "выключить звук")
- Открывает браузер, YouTube, папки
- Делает скриншоты
- Чистит временные файлы и DNS кэш
- Выключает, перезагружает, блокирует ПК
- Открывает камеру и OBS
- Свои команды можно добавлять
- Красивая анимация с качеством от 1 до 6
- Полноэкранный режим (F11)

# Как установить и запустить

Всё делает активатор. Подробная пошаговая инструкция лежит рядом с ним в файле `ИНСТРУКЦИЯ.txt`.

1. Поставь Python 3.11 (64-bit) с python.org, при установке отметь "Add python.exe to PATH".
2. Дважды кликни `START_JARVIS.bat` (он лежит на уровень выше этой папки).

При первом запуске он сам создаст `.venv`, поставит библиотеки, скачает русскую модель Vosk и запустит `11.py`.
Дальше запуск занимает пару секунд. Файлы `requirements-*.txt` нужны только для ручной установки.

# Настройка звуков

В файле `audio_output.py` есть словарь `TRIGGER_SOUNDS`. Добавляй свои команды и звуки:
```
TRIGGER_SOUNDS = {
    "моя_команда": "мой_звук.mp3",
}
```

# Управление

- Кнопка с шестеренкой — настройки
- F11 — полноэкранный режим
- Говори "стоп" или "выход" — закрыть

# Команды

Говори что хочешь, он поймет:

- "звук плюс 10" — увеличить громкость
- "выключи компьютер" — выключить ПК
- "скриншот" — сделать скрин
- "очисти корзину" — очистить корзину
- "открой браузер" — открыть Google
- "ютуб" — открыть YouTube
- "музыка" — открыть папку с музыкой
- "поиск [запрос]" — поиск в Google
- "рестарт" — перезагрузить ассистента

# Программы и игры

Команды вида «открой spotify», «запусти майнкрафт», «открой террарию», «открой blue stacks»: около сотни программ и игр, названия по-русски и по-английски. Полный список раскрывается на странице «Команды» в блоке «Программы и игры».

Программа ищется по ярлыку в меню «Пуск», потом по обычным путям установки, потом по протоколам (spotify:, steam://). Своя программа добавляется одной строкой в таблицу `APPS` в файле `apps.py`, формат описан в начале файла. После запуска играет кастомный звук из `sounds`.

# Распознавание речи

В настройках (вкладка «Звук и голос») можно включить любые движки, в том числе все сразу:

- **Vosk RU / Vosk EN** — офлайн, быстро, без интернета
- **Google RU / Google EN** — онлайн, нужен интернет

Фраза уходит во все включённые движки одновременно. Выполняется первая распознанная известная команда, остальные отбрасываются. По умолчанию включён только Vosk RU.

## Как подключить Vosk
1. Выполни `pip install vosk`
2. Скачай модель (русская: `vosk-model-small-ru-0.22`, английская: `vosk-model-small-en-us-0.15`)
3. Распакуй архив так, чтобы папка модели лежала рядом с `11.py`

Если модель ещё грузится или не найдена, в логе будет сообщение об этом.

# Язык

В настройках выбери «Язык интерфейса» RU или EN. Меняется после перезапуска. Голосовые команды работают на обоих языках: «volume plus one» делает то же, что «звук плюс 1». Числа тоже понимаются по-английски. Логи пока на русском. Динамические сообщения (с именами файлов и ошибками) остаются русскими.

# Фон

В настройках кнопка «Сменить фон» открывает режим настройки: картинку можно двигать мышью, колёсико меняет масштаб. Режимы: на весь экран, кроме левого меню, без фона (по умолчанию). Затемнение и «фон под верхней полосой» настраиваются там же. Картинка копируется в папку `script/backgrounds`. Удачные настройки можно сохранить под именем и потом применять из списка «Сохранённые фоны».

# Жесты камеры

Требуются `opencv-python` и `mediapipe`. Включаются в настройках.
- Открытая ладонь: светодиод рядом с CPU и RAM становится зелёным и ждёт жест 5 секунд.
- Буква «М» в воздухе указательным пальцем: открывается браузер.
- Красный светодиод: камера работает, Jarvis ждёт ладонь.

# Свои команды

Вкладка «Команды»: выбери тип и введи название команды.
- **Файл или программа** — открывает файл, программу или ярлык
- **Папка** — открывает папку в проводнике
- **Сайт** — открывает адрес в браузере (`https://` добавится само)

# Логи

Вкладка «Логи» в настройках: что показывать в консоли при распознавании — время и миллисекунды, длительность и громкость фразы, кто ответил (движок), что распознано, уверенность, решение (команда или нет), задержка после конца фразы, очередь. Настройки применяются сразу. Файл в папке `logs` всегда пишется полностью.

# Голосовой ответ

Галочка "Голосовой ответ после действия" в тех же настройках. Jarvis коротко проговаривает действие ("Открываю браузер"). Для этого нужны `pyttsx3` и русский голос в Windows (обычно есть Microsoft Irina). Озвучка идёт в отдельном потоке и не задерживает выполнение команд. По умолчанию выключена, потому что у тебя уже есть звуки из `audio_output.py`.

# Обращение "Джарвис"

Фраза "Джарвис, звук плюс 10" теперь выполняет команду. Одно слово "Джарвис" по-прежнему работает как приветствие.

# Windows 8.1

Программа сама определяет версию Windows и подбирает библиотеку интерфейса. Qt 5.15 официально поддерживает Windows 8.1, а Qt 6 (PySide6) требует Windows 10, поэтому на 8.1 используется PyQt5, а на Windows 10/11 PySide6. Принудительно выбрать можно переменной окружения `JARVIS_QT=PyQt5` или `JARVIS_QT=PySide6`.

## Установка

1. Установи Python 3.11 с python.org (обычный установщик, 64-разрядный). Версия из Microsoft Store не подходит: ей нужна Windows 10. При установке поставь галочку "Add python.exe to PATH". На Windows 8.1 Python 3.11 — самая новая версия, которая работает.
2. Запусти `START_JARVIS.bat`. Он сам определит Windows 8.1, поставит PyQt5 5.15.11 и остальные библиотеки. Если программа вылетит, окно с текстом ошибки не закроется.
3. Русская модель Vosk скачивается автоматически. Если не вышло, распакуй её вручную рядом с `11.py` (см. раздел «Распознавание речи»).

Если Python или pip не запускаются и пишут про `api-ms-win-crt-runtime-l1-1-0.dll`, установи обновления через Центр обновления Windows и Visual C++ Redistributable 2015-2022.

## Что работает иначе на 8.1

- **Скриншот.** Сочетания Win+Shift+S в 8.1 нет. Команда нажимает Win+PrtScn, и весь экран сохраняется в папку "Изображения\Снимки экрана".
- **Камера.** Нужен OBS Studio или приложение "Камера" из Магазина Windows. Если ни того ни другого нет, в логе появится сообщение, а точка в окне станет красной.
- **Голосовой ответ.** Нужен русский голос Windows (Microsoft Irina). Если его нет, ответ отключается, и в логе будет об этом строка.
- **Громкость.** Работает через pycaw. Новые и старые версии библиотеки поддерживаются.

## Если что-то не работает

Открой `logs/jarvis_ДАТА.log`. Самая первая строка показывает версию Windows, Python и выбранный Qt. Пришли её вместе с текстом ошибки.
